# Guía del Estudiante: Flujo de Trabajo y Dudas

Este documento establece las pautas para interactuar con los materiales del curso y gestionar tus propios proyectos.

## 1. Acceso al Repositorio

Tienes dos formas de consultar el material:
1. **Vista Web (Lectura):** A través de [GitHub Pages](https://jmolina-innovacion.github.io/pr1-recursoeducativo/) para estudiar cómodamente.
2. **Vista Código (Fuente):** A través del [Repositorio en GitHub](https://github.com/jmolina-innovacion/pr1-recursoeducativo). Accede aquí para ver el código fuente, los ejemplos reales y proponer cambios.

## 2. Resolución de Dudas (Issues + Blame)
Para preguntar dudas sobre el contenido, utilizaremos el sistema de **Issues** de GitHub, pero de una forma "quirúrgica".

### ¿Cómo preguntar correctamente?
No digas *"no entiendo el tema 1"*. Señala la línea exacta.

1. Ve al archivo en GitHub (ej: `tema1-introgit.md`).
2. Haz clic en el botón **Blame** (arriba a la derecha del código). Verás quién escribió cada línea y cuándo.
3. Haz clic en el número de línea que no entiendes.
4. En el menú de opciones (tres puntos `...`), selecciona **Reference in new issue**.
5. Esto abrirá un Issue con un enlace permanente (permalink) a esa línea exacta.
6. Escribe tu duda. ¡Así sabremos exactamente de qué hablas!

## 3. Tu Entorno de Trabajo

### Generación de Repositorios Privados
Para tus prácticas individuales:
1. Ve a tu perfil de GitHub > pestaña **Repositories**.
2. Pulsa **New**.
3. **Importante:** Selecciona **Private**. Solo tú (y los profesores si nos invitas) podremos verlo.
4. No inicialices con README si vas a subir un proyecto local existente.

### Repositorios en la Organización (Exámenes/Grupos)
Cuando trabajemos en la organización de la asignatura:
1. Accede a la URL de la organización proporcionada.
2. Si usas **GitHub Classroom**, el repo se creará automáticamente al aceptar la tarea.
3. Si debes crearlo manualmente:
    * Pulsa **New Repository** dentro de la organización.
    * Nombra el repo siguiendo el patrón: `DAW-Pruebas-NombreApellido`.
    * Asegúrate de que la visibilidad es la correcta (privado o interno).
